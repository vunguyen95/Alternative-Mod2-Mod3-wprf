# IMPLEMENTATION FOR THE DIFFERENTIAL ATTACKS ON Mod-2/Mod-3 w-PRF

This repository serves as supplement material for the paper " Differential cryptanalysis of Mod-2/Mod-3 constructions of binary weak PRFs ". The work is a collaboration of Thomas Johansson (Lund University), Willi Meier (FHNW), Vu Nguyen (Lund University).
